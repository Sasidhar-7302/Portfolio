# Personal Portfolio Website

This is my personal portfolio website that I developed to showcase my work, projects, and professional experience as a Software Engineer.

## 🚀 Overview
The website features an interactive 3D design, including a rotating project carousel and a holographic hero section, all built using vanilla web technologies.

## 🛠️ Built With
- **HTML5**
- **CSS3** (Custom 3D transforms & animations)
- **JavaScript** (Vanilla ES6+)
- **Mermaid.js** (For architecture diagrams)
