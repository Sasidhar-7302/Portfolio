# Personal Portfolio Website

This is a personal website I developed from scratch to showcase my journey, projects, and specialized skills as a Software Engineer.

## 🚀 Overview
The design focuses on a futuristic, "high-fidelity" aesthetic, combining deep-tech imagery with sophisticated 3D interactions to create a professional and immersive experience.

## 🛠️ Technical Implementation
I built this portfolio using vanilla web technologies to ensure maximum performance and complete control over the 3D physics. Key technical highlights include:

- **3D Rotation Engine**: A custom-built project carousel utilizing CSS `perspective` and `transform-style: preserve-3d`. The positioning of the cards is calculated mathematically via JavaScript to form a perfect 3D circle.
- **Responsive 3D Geometry**: The carousel's radius dynamically scales based on the viewport (e.g., from 540px on desktop to 280px on mobile) to ensure a seamless experience across all devices.
- **Interactive Input Handling**: Implemented custom event listeners for both Mouse and Touch (swiping), allowing for manual rotation and interaction with the project gallery.
- **Holographic Hero Section**: Created a volumetric depth effect using 12 discrete layers of CSS transformation that react to mouse position.
- **Live Architecture Diagrams**: Integrated `Mermaid.js` to render live system design blueprints for every project, emphasizing my focus on distributed systems and software architecture.

## ⚙️ Built With
- **HTML5** & **Vanilla CSS3** (no external UI frameworks)
- **Vanilla JavaScript** (ES6+)
- **Mermaid.js** (Architectural visualization)
- **Git** (Version control and deployment)
