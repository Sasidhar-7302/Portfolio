## 🎡 The Portfolio Experience
This is not a template. It is a custom-engineered 3D experience built for performance and professional impact.

- **3D Rotating Carousel**: A hardware-accelerated project gallery utilizing CSS `perspective` and `rotateY` transforms, synchronized with background orbit rings.
- **Holographic Hero**: A 12-layer volumetric depth effect that reacts to mouse/touch input, built with vanilla CSS.
- **System Architecture Blueprints**: Live-rendered `Mermaid.js` diagrams for every major project, showcasing structural design over basic code.
- **Local-First Philosophy**: Highlighting my work on air-gapped AI (GI Scribe) and autonomous local assistants (Chintu AI).

## 🛠️ Tech Stack
This portfolio is a testament to mastering the fundamentals for maximum performance:
- **Core**: Vanilla JavaScript (ES6+), HTML5 Semantic Structure.
- **Styling**: Vanilla CSS3 (Custom 3D Engine, Glassmorphism, Responsive Grid).

- **Optimization**: Zero external frameworks for sub-100ms load times and perfect SEO.
